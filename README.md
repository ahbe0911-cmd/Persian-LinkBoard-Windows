# Persian LinkBoard Windows

لانچر لینک‌های کاربردی برای ویندوز با رابط فارسی و راست‌به‌چپ.

## هدف نسخه 0.1
- سازگار با Windows 8.1 / 10 / 11
- رابط WPF روی .NET Framework 4.8
- کارت‌های لینک با جستجو
- افزودن، ویرایش و حذف لینک‌ها
- دسته‌بندی ساده
- ذخیره اطلاعات کاربر در AppData
- طراحی تیره و مینیمال فارسی
- GitHub Actions برای ساخت خروجی ویندوز

> این نسخه پایه است و ظاهر و امکانات آن در مراحل بعدی به طرح گرافیکی نهایی نزدیک‌تر می‌شود.
